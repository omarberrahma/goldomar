# Elite Omar - Haute Joaillerie

A premium, high-end jewelry e-commerce landing page built with React, Vite, and Tailwind CSS v4.

## Features

- **Interactive UI/UX**: Premium dark theme with gold metallic accents and glassmorphism.
- **Gold Dust Effect**: Custom interactive particle background.
- **Live Gold Prices**: Real-time simulation of gold price fluctuations (24k, 22k, 18k).
- **Product Catalog**: Dynamic filtering and detailed product views.
- **Shopping Cart**: Fully functional cart with global state management via React Context.
- **Interactive Ring Finder**: Digital tool to find perfect ring sizes.
- **WhatsApp Integration**: Secure checkout and order confirmation via WhatsApp.
- **Security Best Practices**: Sanitized data payloads and mitigated Reverse Tabnabbing.
- **Fully Responsive**: Optimized for all devices with RTL support.

## Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite 8
- **Styling**: Tailwind CSS v4
- **Icons**: Font Awesome 6
- **Fonts**: Plus Jakarta Sans, Playfair Display, Amiri

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Project Structure

- `src/components/`: Modular UI components.
- `src/context/`: Global state management (Cart).
- `src/data/`: Product database and constants.
- `src/index.css`: Tailwind v4 theme configuration and custom styles.
- `src/App.jsx`: Main application composition.
